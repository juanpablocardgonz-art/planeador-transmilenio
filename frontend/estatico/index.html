R1 Buscar una estación

Bajo el capó

Tabla hash propia con encadenamiento (motor/tabla_hash.py): nombre → estación. Función hash polinomial, rehash al superar factor de carga 0.75.

Complejidad: O(1) promedio. Alternativa descartada: búsqueda binaria O(log n).

R2 Autocompletar

    Bajo el capó

    Árbol AVL con los nombres de las estaciones abiertas (motor/avl.py). Bajamos hasta el primer nombre ≥ prefijo y recorremos en orden con una pila hasta juntar k o salir del prefijo.

    Complejidad: O(log n + k). Alternativa: Trie (no sirve para rango ni ranking).

    R3 Listar un rango

      Bajo el capó

      El mismo AVL: recorrido en orden que empieza en desde y se detiene al pasar hasta. Las estaciones cerradas no están en el árbol, así que nunca aparecen.

      Complejidad: O(log n + r), r = estaciones devueltas.

      R4 Próximo bus

      Bajo el capó

      Hash (ruta → parada) y búsqueda binaria (lower bound) sobre el arreglo de horas de esa parada, que se ordenó con Merge Sort al cargar (motor/ordenamiento.py).

      Complejidad: O(log h), h = buses de esa ruta en esa estación.

      R5 Planear un viaje

      Bajo el capó

      Grafo estación ↔ ruta. Dos barridos (motor/planificador.py): hacia atrás desde el destino anotando cada posible transbordo, y hacia adelante desde el origen buscando el destino o una estación anotada. Arreglos indexados por id con marcas de versión para no reiniciarlos.

      Complejidad: O(Lorigen + Ldestino), L = largo de las rutas que pasan por ahí.

      R6 Estaciones con más buses al día

      Bajo el capó

      AVL con clave (-buses, nombre): al negar los buses, el recorrido en orden da primero las de más buses y desempata alfabéticamente. Solo se actualiza cuando algo cambia (cerrar, reabrir, editar una ruta): O(log n).

      Consulta: O(log n + k). Alternativa descartada: ordenar todo en cada consulta, O(n log n).

      R7 Editar rutas

        Para quitar una parada, haz clic en ella dentro del recorrido.

        Bajo el capó

        Lista doblemente enlazada de paradas + tabla hash estación → nodo en cada ruta (motor/lista_doble.py). Insertar o quitar: O(1) (+ O(log n) para el ranking). Recorrer en cualquier sentido: O(L).

        R8 Cerrar y reabrir

        Bajo el capó

        Cerrar = sacar la estación de los dos AVL (nombres y ranking) y marcarla cerrada; el planificador la salta. Un solo método interno actualiza todas las estructuras: O(log n).

        R9 Deshacer y rehacer

        Cada cambio es un comando que sabe aplicarse y revertirse, guardado en dos pilas (LIFO). Un cambio nuevo vacía la pila de rehacer.

        Bajo el capó

        motor/historial.py — patrón Command. Apilar/desapilar O(1) + el costo de la operación revertida.

        R10 Simular hora pico

        Bajo el capó

        Cola FIFO sobre arreglo con índice de frente (motor/pila_cola.py, motor/simulacion.py). Por cada bus: entran a la cola los que ya llegaron y suben hasta llenar la capacidad.

        Complejidad: O(P + B). Con list.pop(0) sería O(P²).

        R11 Panel de rendimiento

        Cada operación se mide con la red real (n) y con copias de 2n, 4n y 8n. Si al duplicar n el tiempo crece como dice la complejidad esperada, la decisión fue correcta.
